# Project rules

- Use English for code, comments, documentation, and UI text.
- This application is local only. Do not add public hosting or household telemetry.
- Never commit credentials, API responses, household data, home IDs, or screenshots of real data.
- Keep runtime state outside this repository. Use synthetic fixtures in tests only.
- Preserve UTC interval identity and home-local calendar grouping, including DST.
- API cost is not an invoice. A hypothetical monthly time-average is not a confirmed tariff.
- Do not infer appliance identity or achievable load shifting from aggregate consumption.
